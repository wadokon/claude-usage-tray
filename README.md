# ClaudeUsageTray

Claude の使用量（5時間枠・週間枠）をデスクトップに常駐表示する Windows 用ウィジェットです。ブラウザで使用状況ページを開かなくても、残量が常に視界に入ります。

- タスクトレイのアイコンに **5時間枠の残量%** を数字で表示（下部のバーは週間枠の残量）
- デスクトップの小さなウィジェットに **枠ごとの残量バーとリセット時刻**を表示
- 残量に応じて色が変化（50%以上=緑 / 20%以上=橙 / それ未満=赤）
- 単体 exe で動作、追加ランタイム不要

## ⚠️ はじめにお読みください

- 本ツールは **非公式** です。Anthropic 社とは一切関係ありません
- 使用量の取得には **公開ドキュメントに記載の無いエンドポイント** を利用しています。**予告なく変更・停止され、動作しなくなる可能性があります**
- 認証は **Claude Code のログイン情報**（`~/.claude/.credentials.json`）を読み取って利用します
  - 読み取ったトークンは Anthropic の API へのリクエストにのみ使用し、**それ以外のどこにも送信しません**（本リポジトリのソースで確認できます）
  - Claude Code でログイン済みであることが前提です
- 以上を理解したうえで、自己責任でご利用ください

## インストール

1. [Releases](https://github.com/wadokon/claude-usage-tray/releases) から `ClaudeUsageTray.exe` をダウンロード
2. 好きなフォルダに置いてダブルクリックで起動
3. 初回に SmartScreen の警告が出た場合は「詳細情報」→「実行」を選択

.NET Framework 4.x（Windows 10/11 標準搭載）で動作します。PC 起動時に自動で立ち上げたい場合は、`shell:startup` フォルダにショートカットを置いてください。

## 表示の見かた

| 表示 | 意味 |
|---|---|
| `5h` | 5時間枠の残量。数字はトレイアイコンにも出る |
| `週` | 週間枠（全体）の残量 |
| モデル名 | モデル別の週間枠の残量（アカウントによって表示される） |
| 右側の時刻 | その枠がリセットされる時刻（今日ならHH:mm、翌日以降はM/d HH:mm） |
| 右上の `!` と時刻 | 取得に失敗中。表示は最終取得時点の値 |

## 操作方法

| 操作 | 動作 |
|---|---|
| ウィジェットをドラッグ | 移動（位置は記憶される） |
| ウィジェットをダブルクリック | 今すぐ更新 |
| トレイアイコンを左クリック | 更新して詳細をバルーン表示 |
| 右クリック | メニュー（表示切替 / 最前面 / 詳細 / 更新 / 使用状況ページ / 再ログイン / 終了） |

## 動作の仕様

- 2分間隔で自動更新します
- 取得に失敗した場合は間隔を倍にしていき（最大5分）、自動で再試行します
- 一度でも取得できていれば、失敗中は**最後に取得できた値**を表示し続けます（右上に `!` が出ます）
- 認証エラー（401/403）になった場合は、右クリック →「ログイン (Claude Code を起動)」から再ログインしてください

## ビルド

Visual Studio は不要で、Windows 同梱のコンパイラだけでビルドできます。

```bat
%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /codepage:65001 ^
  /target:winexe /out:ClaudeUsageTray.exe ^
  /r:System.dll /r:System.Core.dll /r:System.Drawing.dll ^
  /r:System.Windows.Forms.dll /r:System.Web.Extensions.dll ^
  ClaudeUsageTray.cs
```

## 設定ファイル

| ファイル | 内容 |
|---|---|
| `widget-position.json` | ウィジェットの位置と最前面設定（自動生成） |
| `tray-error.log` | 予期しない例外が発生した場合のみ生成 |

通信ログが必要な場合は、環境変数 `CLAUDEUSAGETRAY_DEBUG=1` を設定して起動すると `poll-log.txt` に記録されます（既定では出力しません）。
